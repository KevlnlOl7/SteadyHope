# STM32 Motor Control

## 專案簡介

本專案為 STM32 馬達控制程式，主要功能是透過 GPIO 控制 H-bridge 馬達驅動模組，讓 DC 馬達進行正轉、停止、反轉與停止的循環動作。

此程式目前主要用於穿戴式抑震裝置專題中的馬達控制測試，確認 STM32 能夠正確輸出控制訊號並驅動馬達運作。

## 使用硬體

- STM32H745I-DISCO 開發板
- H-bridge 馬達驅動模組
- DC 馬達
- 外部電源供應器
- 杜邦線 / 麵包板

## GPIO 腳位設定

| 功能 | STM32 腳位 | 說明 |
|---|---|---|
| AIN1 | PG3 | 馬達控制訊號 1 |
| AIN2 | PA6 | 馬達控制訊號 2 |
| LED1 | PI13 | 測試用 LED |
| LED2 | PJ2 | 測試用 LED |

## 馬達控制邏輯

| AIN1 | AIN2 | 馬達狀態 |
|---|---|---|
| 1 | 0 | 正轉 |
| 0 | 0 | 停止 |
| 0 | 1 | 反轉 |
| 0 | 0 | 停止 |

## 程式功能

程式會在無限迴圈中依序執行以下動作：

1. 馬達正轉 1 秒
2. 馬達停止 1 秒
3. 馬達反轉 1 秒
4. 馬達停止 1 秒

主要控制程式位於：

```text
Core/Src/main.c
```

## 開發環境

- STM32CubeIDE
